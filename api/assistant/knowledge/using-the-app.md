# Using the app
Source: this project's dashboard pages

## Running a scan
Start a scan on the New Inspection page with a video, a batch of photos or a webcam. Video gives the best results, because a defect must be seen in several frames to count.
Detections are saved to the database as the scan runs.

## Reviewing detections
The AI Detections page lists every detection with filters for severity, class and review state.
Quick Review shows detections one at a time so an engineer can confirm or reject each one fast.
A defect's detail page shows its picture, size and history, and lets an engineer flag it as urgent.

## Reports and the twin
The Reports page builds an inspection report with counts by severity and a written summary, downloadable as PDF or CSV.
The digital twin shows the tunnel in 3D with a marker for each defect at its chainage and clock position.

## Ask HRT
Ask HRT answers questions about the defect database with read-only tools and explains terms from these notes. It never changes data.
